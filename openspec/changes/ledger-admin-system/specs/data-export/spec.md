## Purpose

提供收支记录的数据导出与批量操作能力：支持将筛选后或全部的收支记录导出为标准 Excel 文件，支持列表批量选中后执行删除与导出，提升数据管理效率与可用性。

## ADDED Requirements

### Requirement: Excel 数据导出

系统 SHALL 支持将收支记录导出为标准的 .xlsx 文件，导出内容可包含当前筛选后的记录或全部记录；导出的文件格式规整、无乱码、数据完整准确。

#### Scenario: 导出筛选后的记录

- **WHEN** 用户设置筛选条件后点击导出
- **THEN** 系统生成包含该筛选结果记录的 Excel 文件并下载

#### Scenario: 导出全部记录

- **WHEN** 用户点击全量导出
- **THEN** 系统生成包含全部符合权限范围的记录的文件并下载

#### Scenario: 导出文件内容正确

- **WHEN** 用户打开导出的 Excel 文件
- **THEN** 文件无乱码，字段与金额与原列表数据一致

### Requirement: 批量选中与批量删除

系统 SHALL 支持在列表中批量选中多条记录，并对选中的记录执行批量删除。

#### Scenario: 批量删除选中记录

- **WHEN** 用户选中多条记录并点击批量删除并确认
- **THEN** 选中的记录被批量删除并从列表移除

### Requirement: 批量导出

系统 SHALL 支持将批量选中的记录导出为 Excel 文件。

#### Scenario: 批量导出选中记录

- **WHEN** 用户选中多条记录并点击批量导出
- **THEN** 系统生成仅包含选中记录的 Excel 文件并下载
